=====

**運用設計書**を `docs/design/md/運用設計書.md` に作成しました（1 ファイルのみ）。

利用者自身が迷わず操作できるよう、次を固定しています。

- **systemd:** `seaweed.service` の全文。ヒープ・TZ はユニット、秘密は `EnvironmentFile` のみ（BCrypt の `$` を systemd が展開しないようにするため）。
- **起動停止:** `systemctl` の順（止めるときはアプリが先）。ホスト上の health は `curl http://127.0.0.1:8080/api/v1/health`。再起動で全セッション無効。
- **デプロイ:** 開発機で JAR を作り `scp` → 停止して入れ替え。本番に Node / Maven は置かない。
- **認証・DB パスワード:** 画面なし。ハッシュは開発機で BCrypt 12 を作り、`sudoedit` のあと restart。
- **SSH SG:** コンソールで 22 の `/32` を差し替え。`0.0.0.0/0` は禁止。
- **バックアップ（推奨）:** 週 1 回の EBS スナップショット、世代 4。RPO/RTO なし。監視・S3・cron は置かない。
- **切り分け:** 端末 Tailscale → インスタンス → SSH → health → mysqld / Serve の順。
