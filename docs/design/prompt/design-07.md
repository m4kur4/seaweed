=====

`docs/design/md/処理仕様書.md` を 1 ファイルだけ作成しました。

実装時の計算の骨格は次のとおりです。

- **時計:** JST の今日。金額は `BigDecimal`、HALF_UP・小数 2 桁
- **変動費:** 当月を除く直近 3 完了暦月。実績のある月だけで平均。0 ヶ月なら変動費 0 ＋ `variableExpenseMissing`
- **貯金額:** 定期収入月額 − サブスク月額 − 変動費。年額は ÷12
- **未登録:** `updated_on IS NULL` → チャートなし（`available=false`）。貯金額自体は計算する
- **チャート:** 起点月を含め 24 点、各月末。`手元 + 起点より後〜その月末の家計（符号付き） + 貯金額×i`
- **到達:** 調整手元（未来の家計を全部織込）に対し ceil。逆算は希望月との月差 T>0 のときだけ

No.8 認証セキュリティ設計書は、この計算には依存しません。
