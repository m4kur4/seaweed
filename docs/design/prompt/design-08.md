=====

**認証・セキュリティ設計書**を `docs/design/md/認証セキュリティ設計書.md` に作成しました（1 ファイルのみ）。

実装時に迷わないよう、次を固定しています。

- **到達:** `127.0.0.1:8080`、Tailscale Serve、公開 TLS なし。アプリは IP を見ない。SG の CIDR はインフラ設計書へ委譲。
- **アカウント:** `SEAWEED_AUTH_USERNAME` / `SEAWEED_AUTH_PASSWORD_HASH` の 1 件。`users` 表は作らない。起動時に空・非 BCrypt なら Fail fast。
- **ハッシュ:** BCrypt 強度 12。ユーザー名不一致でもダミーハッシュで `matches`。72 バイト超は Encoder に渡さず 401。
- **セッション:** Cookie 名 `SEAWEED_SESSION`、HttpOnly、Secure=false、SameSite=Lax、14 日。メモリ `HttpSession`。URL 追跡なし。
- **Spring Security:** `GET /health` と `POST /login` のみ匿名。他の `/api/v1/**` は 401 JSON（302 しない）。CSRF 無効。403 は使わない。
- **ログイン失敗:** 空欄も 401（400 にしない）。文言は API 設計書どおり。

パスワード変更 UI・MFA・ロック・許可 IP・公開証明書は採用しない、と明記してあります。
