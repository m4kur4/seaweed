=====

`docs/design/html/システム構成設計書.html` を 1 ファイルだけ作成しました。他の設計書・コード・DDL は出していません。

後続の設計と実装で共通になる決めは次のとおりです。

- **待受:** アプリは `127.0.0.1:8080`。公開 NIC には出さない。Tailscale Serve が閉域の **:80 → 8080**。
- **URL:** `http://seaweed/`（MagicDNS）。公開ドメイン・証明書なし。Nginx なし。SPA と API は同一オリジン（CORS なし）。
- **画面パス:** `/login` `/` `/ledger` `/subscriptions` `/investments` `/incomes` `/settings`
- **API:** `/api/v1`。入口だけ `health` と `auth/login|logout|me` を固定。
- **設定:** `/etc/seaweed/seaweed.env`。キー名（`SEAWEED_AUTH_*`、データソース等）を固定。
- **ビルド:** Vite → `static/` 同梱 → `seaweed.jar`。DB は `127.0.0.1:3306` / `seaweed`。Flyway なし。
- **ローカル:** Vite `:5173` が API をプロキシ。Tailscale は必須にしない。

ハッシュやセッション、SG、計算式は書いていません。認証・インフラ・API・処理仕様へ委譲しています。

ブラウザで HTML を開き、構成図が出ることと、パス・キーに異論がないかを見てから No.2 に進むのがよいです。
